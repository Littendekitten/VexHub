# VexHub — Vexuno Studio

A responsive, browser-based game hub for Vexuno Studio, built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step, package manager or server is required.

## Publish with GitHub Pages

1. Upload the contents of this folder to the root of your GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`, then save.

## Included

- Dashboard, Discover, My Library and Settings views
- Search across the listed game
- Save/remove a game from the local favourites library
- Local profile display name and accent-colour preferences
- Reduced-motion preference
- Responsive layout for desktop, tablet and mobile
- No external JavaScript libraries or backend required

## Important notes

This is a front-end client preview. The uploaded Vexuno project only contained a basic studio landing page and did not include game files, a game launcher API, user authentication, downloads or online accounts. Accordingly, the upcoming game is presented as **Coming Soon**; install, launch, account and multiplayer features need real game/backend services before they can be enabled.
